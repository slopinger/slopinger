### things i build & maintain
- **[slopbgp](https://github.com/slopinger/slopbgp)** — autonomous BGP-4 & MP-BGP routing daemon in Gleam on Erlang/OTP BEAM for DN42
- **[slop-landing](https://github.com/slopinger/slop-landing)** — official landing page and slime engine for [freifick.net](https://freifick.net)
- **[lantern](https://github.com/slopinger/lantern)** — experimental webserver in Haskell with Caddy-style config, HTTP/1, TLS 1.3, and ACME
  - **[lantern-tls](https://github.com/slopinger/lantern-tls)** — clean-room TLS 1.3 protocol library in Haskell
  - **[lantern-http](https://github.com/slopinger/lantern-http)** — strict HTTP/1 wire protocol library in Haskell
- **[trough](https://github.com/slopinger/trough)** — lightweight ActivityPub server in Go + SQLite with web UI and Mastodon client API support
- **[slopbox](https://github.com/slopinger/mayfly)** — ephemeral file host written in Gleam on Erlang/OTP
- **[driftline](https://github.com/slopinger/driftline)** — static OpenAPI schema difference and migration analyzer
- **[therapie-mcp](https://github.com/slopinger/therapie-mcp)** — Python Model Context Protocol server for directory search and enquiry workflow
- **[arbeitsagentur-mcp](https://github.com/slopinger/arbeitsagentur-mcp)** — MCP server for German employment agency APIs and deadlines
- **[dn42](https://github.com/slopinger/dn42)** — DN42 BGP routing and WireGuard peering infrastructure (`AS4242420125`)
- **[server-backups](https://github.com/slopinger/server-backups)** — verified daily SQLite and upload backup pipeline
- **[nixfiles](https://github.com/slopinger/nixfiles)** — declarative NixOS configuration for the freifick.net server
